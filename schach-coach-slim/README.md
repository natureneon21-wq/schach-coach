# Schach-Coach

Schach lernen mit der animierten Trainerin Mira – nach der Russischen Schule: nicht Zugfolgen auswendig lernen, sondern jede Stellung durchdenken.

## Was die App kann

- **Partien gegen Bots** (ca. 200 bis 1000 Elo), jeder deiner Züge wird bewertet (Bester Zug, Gut, Ungenauigkeit, Fehler, Patzer).
- **Mira fragt zuerst, erklärt dann**: Bei Fehlern stellt sie eine Leitfrage, bietet „Zug zurücknehmen“ an und zeigt die Lösung erst auf Wunsch. Der Tipp-Knopf hat vier Stufen (Frage, Hinweis, Figur, Zug).
- **Denk-Routine**: die 5 Fragen vor jedem Zug.
- **Analyse nach der Partie**: Genauigkeit, Bewertungsverlauf, alle Züge markiert, Sprung zum nächsten Fehler.
- **Aufgaben aus eigenen Fehlern**: Fehler aus analysierten Partien werden zu Übungsstellungen.
- **Gemini (optional)**: Mit eigenem API-Key erklärt Gemini Fehler und fasst Partien zusammen. Die Bewertung selbst kommt immer von Stockfish.

Alles läuft im Browser, auch offline (nach dem ersten Laden). Keine Daten verlassen das Handy, außer Anfragen an Gemini, wenn du einen Key einträgst.
